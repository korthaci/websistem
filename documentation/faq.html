Frequently Asked Questions (FAQ)

Bu sayfa Websistem v1.0 hakkında en çok sorulan soruların yanıtlarını içerir.

General

What is Websistem?
Websistem is a lightweight, PHP-based web management system focused on simplicity, clarity, and control. It provides a clean admin panel, theme system, and modular structure without the overhead of large frameworks or CMS platforms.
Is Websistem a CMS or a framework?
Neither — and intentionally so. Websistem sits between a classic CMS and a custom-coded project:
  • More structured than a raw PHP setup
  • Less complex than full CMS or framework solutions
Who is this system for?
  • Freelancers building client websites
  • Developers who want full control without heavy abstractions
  • Designers who need a manageable admin panel
  • Small to medium-scale projects
Who is it NOT for?
  • Enterprise-scale applications
  • Plugin-marketplace–driven ecosystems
  • CLI-first or headless-only workflows
  • Projects that require real-time or highly distributed systems

Installation & Usage

Is installation complicated?
No. Installation is handled through a web-based wizard and takes only a few minutes. No command line usage is required.
Can I use MySQL or SQLite?
Yes. Both MySQL and SQLite are supported and selectable during installation.
Can I migrate from SQLite to MySQL later?
This is not officially supported in v1.0. Database selection is intended to be final per installation.

Admin Panel

Can multiple users log in?
Yes. The system supports multiple users with different permission levels.
Are deleted items recoverable?
No. Deleted pages, blocks, menus, and themes cannot be restored. However:
  • Publish/unpublish actions are reversible
  • Some changes are logged internally
  • Modules remain reusable as long as their folders exist
Does changing a theme delete my content?
No. Content remains intact. However, each theme has its own default homepage block structure. When switching themes, the system may suggest loading theme-specific default blocks.

Themes & Customization

Can I create my own theme?
Yes. Themes are HTML-based and fully customizable. Theme creation is documented at a conceptual level; no framework knowledge is required.
Do themes control menus?
Yes. Menu rendering depends on the theme’s menu.html structure. If a dynamic marker is present, menus are generated automatically. If not, the HTML is rendered exactly as written.

Modules

What is a module?
A module is a self-contained feature that can be embedded into pages or blocks using a short code. Example: [al:modul:example_module]
Can I create custom modules?
Yes, but module development requires PHP knowledge. Module development details are intentionally kept minimal in documentation.

Translation & Languages

Does Websistem support multiple languages?
Yes. The system includes a built-in translation and language management system.
Can I enable or disable languages?
Yes. Languages can be managed directly from the admin panel.
Do I need to use the translation system?
No. If you are building a single-language website, you can safely ignore it.

Licensing & Support

Is Websistem open source?
Parts of the system may be open, but distribution terms depend on where you obtained it. Always refer to the included license file.
Can I use it for commercial projects?
Yes. You can build and sell websites for clients using Websistem.
