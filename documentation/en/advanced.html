Websistem v1.0 - Advanced Architecture & Extension Guide

This section is for developers who want to understand internal behavior and extend safely.

1. Architecture Philosophy

  • Lightweight and readable structure
  • Clear separation between content and presentation
  • Admin panel and frontend kept isolated

The core engine is responsible for routing, processing order, and module coordination. Themes stay HTML-only and define markup and layout; no PHP logic is embedded into template files. The goal is strict separation of logic and presentation rather than deep abstraction layers.

2. Request Flow (High-Level)

Request Flow
Request -> index.php -> core routing -> active theme -> HTML output

2.1 Core Engine Capabilities

  • URL routing and resolution
  • Central processing pipeline
  • Directive parsing
  • Placeholder replacement
  • Conditional block evaluation
  • Template include resolution
  • Module execution flow

3. Theme Behavior

Theme switching changes visual rendering and layout mapping, not the content source itself.

Example Theme Directory
/theme/minimal/
header.html
footer.html
index.html
assets/

Themes are file-system based and HTML-first. They consist of HTML, CSS and JavaScript assets, while the engine injects data into predefined placeholders during rendering.

4. Menu and data-dynamic

If menu.html contains data-dynamic, the system builds menu items dynamically.

5. Module Model

Modules are loaded from module directories and inserted through shortcodes.

  • Enable/disable control per module
  • Tight integration with the core, while staying separate from theme files
  • Feature-based extension model
  • Controlled execution flow

6. Template Syntax

The template engine provides dynamic behavior inside otherwise static HTML templates.

  • Data injection placeholders
  • Conditional rendering blocks
  • Nested condition evaluation
  • Include directives
  • Language-aware regions
HTML Template Structure
{{$:title}}
                        {{__if%active%
                        Content if active
                        ||
                        Content if passive
                        __endif}}
                        {{__foreach %key->%item}}
                        <div>{{%item%.name%}}</div>
                        {{__endforeach}}
Syntax Warning

Do not add spaces inside variable placeholders. Correct: {{$:variable}}. Incorrect: {{$: variable }}.

If syntax: {{__if%key% content || alternative __endif}} (no spaces, multiline supported).

Foreach syntax: {{__foreach %key->%item}} (-> required, no spaces).

This matches md/template_kullanim_rehberi.md syntax conventions.
