Websistem v1.0 - Getting Started

This guide gives first-time users a clear overview of the system, expected workflow, and capabilities.

1. What Is This System?

Websistem v1.0 is a lightweight web core designed for fast, simple, and flexible project delivery.

It avoids heavy CMS complexity and focuses on practical features for developers who prefer direct control.

Our Vision

Reduce complexity, increase speed, keep control in developer hands.

2. What It Is Not

  • Not a heavyweight framework with a long learning curve.
  • Not a plugin-heavy CMS stack.
  • Not a CLI-only workflow.
  • Not a zero-knowledge boxed product.

3. Who Is It For?

  • Web Designers: people who know HTML/CSS and want dynamic structure quickly.
  • Freelancers: developers who need a clean and manageable admin experience for clients.
  • Lightweight Builders: teams that want a controlled, minimal core.

4. Required Technical Level

  • Basic HTML editing
  • Basic CSS adjustments
  • Understanding folder/file structure

5. What You Can Build

  • Corporate websites
  • Portfolio and personal pages
  • Blog/news sites
  • Product showcase websites

6. Core Concepts

  • Core: routing and processing foundation.
  • Admin Panel: content and settings management.
  • Themes: frontend presentation layer.
  • Modules: optional feature extensions.

7. Typical Workflow

  1. Install
  2. Configure
  3. Apply/Customize theme
  4. Add content
  5. Publish

8. How To Read This Documentation

  • Getting Started: conceptual overview
  • Usage: daily admin operations
  • Advanced: architecture and extension details
