System Architecture Overview

The engine is built on strict separation between logic and presentation.

Core Engine

  • URL routing
  • Central processing pipeline
  • Directive parser
  • Placeholder replacement
  • Conditional block evaluation

Theme System

Themes are file-based and HTML-first. No embedded PHP logic inside template files.

Directive System

Supports data injection, conditionals, includes, and language-aware blocks.

Module Architecture

Modules integrate into core flow while remaining isolated from presentation files.

Content Management Layer

  • Page creation/editing
  • Tab-based segmentation
  • Menu binding
  • Gallery integration

Admin Controls

  • Theme selection/editing
  • Page and tab management
  • Module enable/disable
  • Menu management

Language and Translation

Template and content level multilingual support is built in.

Architecture Summary

  • No framework dependency
  • HTML-first model
  • Modular extension strategy
  • File-based theme structure
