Websistem v1.0 - Usage Guide

This guide explains day-to-day management actions in the admin panel.

1. Admin Login

Users and admins use the same login page. Access level is role-based.

2. Sidebar Structure

  • Edit: pages, tabs, menus, blocks
  • Images
  • Files
  • Modules
  • Members
  • Themes
  • General Settings

3. Content Management Layer (Conceptual)

Content is organized through pages, tab-based sections and homepage blocks.

  • Pages hold main text, title, metadata and optional galleries.
  • Tabs group related pages into segments or categories.
  • Blocks build the homepage from top to bottom as ordered sections.
  • Menus bind to pages and tabs to create navigation.

With this structure you can easily build blogs, corporate sites, portfolios, news portals and product showcases on the same core.

4. Edit Menu

4.1 Pages

  • Create, reorder, publish/unpublish pages
  • Attach pages to tabs if needed
  • Add title/content/gallery per page

This section is where you publish and manage your main articles and content pages.

4.2 Tabs

Tabs are used for grouping page sets.

They work well as category-like groupings for articles or sections.

4.3 Menus

Menu entries can come from pages, tabs, or custom title + URL.

4.4 Homepage Blocks

Blocks are ordered homepage sections stored and managed from admin.

They control everything on the homepage between header and footer. Each block is HTML-based and requires basic HTML understanding for best results.

5. Images & Files

System keeps uploaded images and file assets managed separately.

6. Modules

Modules can be enabled/disabled and embedded via shortcode.

Shortcode
[al:modul:module_name]

In the admin panel, each module row includes a copy button. Clicking it copies the shortcode to your clipboard so you can paste it into any page or block content area.

Example: Contact Form
[al:modul:contact-form]

7. Members

Create and edit members with role-based access permissions.

The system includes a built-in membership and authorization layer, allowing you to define different roles and control admin-panel access levels.

8. Themes

Theme switching does not delete content; it changes rendering/layout behavior.

Themes can be edited, duplicated or created from scratch. Theme files are plain HTML, CSS and JavaScript; you can customize both homepage and inner page layouts through the theme editor.

In the theme editor you have access to files such as header.html, footer.html and index.html, which define the global skeleton of the site.

9. Translation System

Language management supports manual and AI-assisted translation flows.

In templates, UI texts are marked using the middle-dot character:

Example
·Log out·
<div>·Welcome to our site·</div>

These markers are converted to the active language while rendering.

10. General Settings

Site title, admin email, and SEO metadata are configured here.

11. Important Defaults

  • Deleted items cannot be recovered.
  • Unpublish is not delete.
  • Some actions are logged but not reversible.
