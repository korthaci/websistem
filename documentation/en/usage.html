Websistem v1.0 - Usage Guide

This guide explains day-to-day management actions in the admin panel.

1. Admin Login

Users and admins use the same login page. Access level is role-based.

2. Sidebar Structure

  • Edit: pages, tabs, menus, blocks
  • Images
  • Files
  • Modules
  • Members
  • Themes
  • General Settings

3. Edit Menu

3.1 Pages

  • Create, reorder, publish/unpublish pages
  • Attach pages to tabs if needed
  • Add title/content/gallery per page

3.2 Tabs

Tabs are used for grouping page sets.

3.3 Menus

Menu entries can come from pages, tabs, or custom title + URL.

3.4 Homepage Blocks

Blocks are ordered homepage sections stored and managed from admin.

4. Images & Files

System keeps uploaded images and file assets managed separately.

5. Modules

Modules can be enabled/disabled and embedded via shortcode.

Shortcode
[al:modul:module_name]

6. Members

Create and edit members with role-based access permissions.

7. Themes

Theme switching does not delete content; it changes rendering/layout behavior.

8. Translation System

Language management supports manual and AI-assisted translation flows.

9. General Settings

Site title, admin email, and SEO metadata are configured here.

10. Important Defaults

  • Deleted items cannot be recovered.
  • Unpublish is not delete.
  • Some actions are logged but not reversible.
