Roadmap

Bu doküman Websistem projesinin planlanan yönünü ana hatlarıyla belirtir.

Burada listelenen öğeler niyetleri temsil eder, garanti teşkil etmez.

Planned for v1.x

Internationalization Improvements

  • Translation system stabilization
  • Improved error handling for dynamic content translation
  • Better language management experience in the admin panel
  • New languages to be added: Español, Italiano, Português, Indonesia, Hindi, Japan

Admin Panel Enhancements

  • UI/UX refinements
  • Performance improvements on large datasets
  • Minor usability improvements based on usage patterns

Theme & Layout

  • More flexible theme configuration options
  • Cleaner separation between content and presentation
  • Improved default theme examples

Under Consideration

Module Ecosystem

  • Optional new built-in modules
  • Better module configuration experience
  • Improved module documentation

Developer Experience

  • Clearer internal structure documentation
  • Small quality-of-life improvements for contributors

Out of Scope (For Now)

  • No plan for a full framework rewrite
  • No plugin marketplace
  • No enforced CLI-based workflow

Bu yol haritası bilinçli olarak ihtiyatlı tutulmuştur. Websistem; kararlılığa, basitliğe ve uzun vadeli sürdürülebilirliğe öncelik verir.
