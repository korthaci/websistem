Websistem v1.0 - Installation Documentation

This page explains how the installer works and what it configures during first-time setup.

1. Installer Purpose

  • Run stable first-time installation in one flow.
  • Minimize manual file editing.
  • Create consistent project bootstrap for v1.0.
Downloaded Package Contents (Overview)
  • Core PHP files and engine structure
  • Documentation files
  • install/ directory and installer scripts
  • Folder structure for uploaded images and other files
  • api/ endpoints for REST-style access
  • theme/ directory with HTML, CSS and JS templates

2. Installation Flow

A typical first-time installation looks like this:

  1. Upload all files from the ZIP package to your server.
  2. Open https://yourdomain.com/install in a browser.
  3. Choose your database type:
    • MySQL for long‑term, high‑traffic projects.
    • SQLite for small, lightweight deployments.
  4. If you use MySQL, enter the database name, user and password from your hosting panel.
  5. If your server has no SSL yet, disable “force SSL” in advanced options.
  6. Define the site title, admin email and admin password.
  7. Review the summary and confirm to write config files and finalize installation.

3. Requirements Check

  • PHP >= 8.0
  • Required extensions (PDO, etc.)
  • Writable paths for config/runtime files

4. Database & Server Configuration

  • MySQL: production
  • SQLite: light deployments.

Protocol and host behavior (HTTP/HTTPS, www/non-www, subdirectory) are configured here.

5. Admin Account

Setup defines site title, admin email, and admin password.

6. Generated Files

File Purpose
rlv.php Core/database settings
.env Secrets and runtime keys
.htaccess Routing/redirect rules
install/installed Installation lock

7. Troubleshooting

System already installed

It means install/installed exists.

Database connection error

Verify credentials and server/service state.

Write permission error

Check file permissions and host restrictions.

Installer is designed for one-time setup, not ongoing configuration work.
