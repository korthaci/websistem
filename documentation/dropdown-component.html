📚 Kullanım Dökümanı

🎯 Temel Kullanım

Dropdown component'i kullanmak için sadece HTML yapısını oluşturun ve data-ws-dropdown attribute'unu ekleyin. JavaScript otomatik olarak tüm dropdown'ları başlatır. 

                <div class="ws_dropdown" data-ws-dropdown>
                    <button class="ws_dropdown_toggle" type="button">
                    <span>Menü Başlığı</span>
                    <svg class="ws_dropdown_icon" viewBox="0 0 20 20" fill="currentColor">
                    <path fill-rule="evenodd" d="M5.293 7.293a1 1 0 011.414 0L10 10.586l3.293-3.293a1 1 0 111.414
                    1.414l-4 4a1 1 0 01-1.414 0l-4-4a1 1 0 010-1.414z" clip-rule="evenodd"/>
                    </svg>
                    </button>

                    <div class="ws_dropdown_menu">
                    <ul class="ws_dropdown_list">
                    <li class="ws_dropdown_item" data-value="option1">Seçenek 1</li>
                    <li class="ws_dropdown_item" data-value="option2">Seçenek 2</li>
                    </ul>
                    </div>
                    </div>

🎨 CSS Sınıfları ve Seçenekler

Boyut Varyantları

  • .ws_sm - Küçük boyut (8px padding)
  • varsayılan - Normal boyut (12px padding)
  • .ws_lg - Büyük boyut (16px padding)

Hizalama Seçenekleri

  • varsayılan - Sola hizalı (left: 0)
  • .ws_align_right - Sağa hizalı (right: 0)
  • .ws_align_center - Ortaya hizalı (center)

Stil Varyantları

  • varsayılan - Solid renkli buton
  • .ws_variant_primary - Gradient arka plan
  • .ws_variant_outline - Sadece border

Item Durumları

  • .ws_selected - Seçili item (vurgulanır)
  • .ws_disabled - Devre dışı item (tıklanamaz)
  • .ws_dropdown_divider - Ayırıcı çizgi

⚡ JavaScript Event'leri

Dropdown bir item seçildiğinde custom event dispatch eder. Bu event'i dinleyerek seçilen değeri yakalayabilirsiniz: 

                // Tüm dropdown seçimlerini dinle
                    document.addEventListener('ws-dropdown-select', function(e) {
                    console.log('Seçilen değer:', e.detail.value);
                    console.log('Seçilen text:', e.detail.text);
                    console.log('Seçilen element:', e.detail.element);
                    });

                    // Belirli bir dropdown'u dinle
                    const myDropdown = document.querySelector('#myDropdown');
                    myDropdown.addEventListener('ws-dropdown-select', function(e) {
                    console.log('Değer:', e.detail.value);
                    });

🔧 Özelleştirme

CSS Değişkenleri

Tüm renkler ve boyutlar CSS değişkenleri ile kontrol edilir. :root içindeki değişkenleri değiştirerek component'in görünümünü özelleştirebilirsiniz: 

                :root {
                    --ws-primary: #2a2a2a;
                    --ws-accent: #ff6b35; /* Ana renk */
                    --ws-accent-dark: #e85a2a; /* Hover rengi */
                    --ws-bg: #fafafa;
                    --ws-surface: #ffffff;
                    --ws-border: #e0e0e0;
                    --ws-radius: 10px; /* Border radius */
                    --ws-transition: 0.2s cubic-bezier(0.4, 0, 0.2, 1);
                    }

Badge Ekleme

Dropdown item'lara badge ekleyebilirsiniz: 

                <li class="ws_dropdown_item" data-value="pro">
                    Pro Plan
                    <span class="ws_dropdown_badge">New</span>
                    </li>

📋 Örnek Kombinasyonlar

                <!-- Küçük boyut + Sağa hizalı -->
                    <div class="ws_dropdown ws_sm ws_align_right" data-ws-dropdown>
                    ...
                    </div>

                    <!-- Büyük boyut + Ortaya hizalı + Primary variant -->
                    <div class="ws_dropdown ws_lg ws_align_center ws_variant_primary" data-ws-dropdown>
                    ...
                    </div>

                    <!-- Outline variant + Normal boyut + Sola hizalı -->
                    <div class="ws_dropdown ws_variant_outline" data-ws-dropdown>
                    ...
                    </div>

💡 İpucu: Tüm class'lar ws_ prefix'i ile namespace'lenmiştir. Bu sayede başka kütüphanelerle çakışma riski yoktur ve component tamamen izole çalışır.
