🎯 Temel Kullanım

Dropdown bileşeni CSS-first bir yaklaşımla tasarlanmıştır. Sadece gerekli HTML yapısını oluşturun ve data-ws-dropdown özniteliğini ekleyin. JS dosyası bu özniteliğe sahip tüm elemanları otomatik olarak algılar ve çalıştırır.

<div class="ws_dropdown ws_accent" data-ws-dropdown>
  <button class="ws_dropdown_toggle" type="button">
    <span>Dropdown Başlığı</span>
    <svg class="ws_dropdown_icon" ...>...</svg>
  </button>
  <div class="ws_dropdown_menu">
    <ul class="ws_dropdown_list">
      <li class="ws_dropdown_item" data-value="1">Seçenek 1</li>
      <li class="ws_dropdown_item" data-value="2">Seçenek 2</li>
    </ul>
  </div>
</div>

⚡ JavaScript Event'leri

Bir seçenek seçildiğinde element üzerinden ws-dropdown-select eventi fırlatılır:

document.addEventListener('ws-dropdown-select', (e) => {
  console.log('Seçilen Değer:', e.detail.value);
  console.log('Seçilen Text:', e.detail.text);
});
💡 İpucu: Tüm sınıflar ws_ öneki ile başlar. Bu sayede mevcut projelerinizdeki CSS sınıfları ile çakışma yaşanmaz ve bileşen tamamen izole çalışır.
